01

School Management System

A complete web-based architecture designed to manage the administrative lifecycle of a school. It replaces manual paperwork with a centralized database for tracking students, educators, academic performance, and institutional resources.

Key Features

  • Role-based access control (Admin, Teacher, Student)
  • Automated grade calculations and report generation
  • Centralized class and resource scheduling

02

Smart Blind Stick

An applied hardware project bridging the gap between embedded programming and real-world accessibility. Built using Arduino, it actively detects physical obstacles to assist visually impaired individuals in navigating their environment safely.

Key Features

  • Real-time ultrasonic obstacle detection
  • Haptic and auditory feedback systems (Buzzer/Vibration)
  • Lightweight, battery-powered portable design

Tech Stack

  • Arduino
  • C++
  • Hardware Integration

04

Personal Portfolio

A custom-built digital identity avoiding generic templates. Designed around a strict 8-point grid, editorial typography, and a handcrafted theme-switching architecture to present work with deliberate visual hierarchy.

Key Features

  • Flash-free system/light/dark theme persistence
  • Fluid typography scaling using CSS clamp()
  • Asymmetric CSS Grid layouts without frameworks
