Behind the builds.

A complete web-based architecture designed to manage the administrative lifecycle of a school. It replaces manual paperwork with a centralized database for tracking students, educators, academic performance, and institutional resources.

Key Features

  • Role-based access control (Admin, Teacher, Student)
  • Automated grade calculations and report generation
  • Centralized class and resource scheduling

Tech Stack

  • HTML
  • CSS
  • JavaScript
  • PHP
  • MySQL
